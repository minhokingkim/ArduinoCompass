Enhances multi-axis sensing capabilities on Arduino boards with tri-axis magnetometry, real-time-processing, and auto-scaling via advanced algorithmic library integration.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ArduinoCompass.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
